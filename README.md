# LCS - Longest Common Subsequence

O **LCS** é um algoritmo que encontra a maior subsequência comum entre duas sequências, mantendo a ordem dos elementos, sem exigir que sejam consecutivos.

## Exemplos

```text
X = "ABCDEF"
Y = "ACE"
LCS = "ACE"

X = "AGGTAB"
Y = "GXTXAYB"
LCS = "GTAB"

X = "ABC"
Y = "DEF"
LCS = ""
```
